Accessibility

We want this website to be usable by as many people as possible. The starter design includes semantic headings, keyboard-friendly navigation, visible focus states, reduced-motion support, alternative text and responsive layouts.

Using the website

You should be able to zoom text, navigate with a keyboard, use common screen readers and view the website on mobile, tablet and desktop devices.

Known limitations

Placeholder images should be replaced with meaningful alternative text when real church photographs are added. Any future video, live stream, online giving or third-party form integration should also be checked for accessibility.

Feedback

If you have difficulty using this website, please contact rccglwfollowupteam@rccglwpm.org.uk or call 07904 776789.
